# のびのび飛竜くん（試作）

ごちそうを食べて体をのばし、60mの竜をめざすミニゲームです。スマホのブラウザで遊べます。

- `index.html` … ゲーム本体（これ1つで動きます）
- `ranking-gas/Code.gs` … ランキング用の Google Apps Script（スプレッドシートに付けて使う）

飛竜くんは浜北商工会青年部のキャラクターです。

## ほかのゲーム（試作）

- `hanabi/index.html` … 花火ドーン！（花火がいちばん高い所でタップして開かせる）
- `tenryu/index.html` … 天竜川くだり（指で左右に動かして、岩や流木をよける）
- `games/index.html` … 3つのゲームの入口（リンクページ）
